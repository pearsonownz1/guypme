# guyp.me

Personal resume site for [Guy Pearson](https://guyp.me).

## Stack

- Next.js (App Router)
- Vercel
- Supabase

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Portrait lives at `public/photo.jpg`.
